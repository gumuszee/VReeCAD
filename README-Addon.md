# BlocksCAD

Intuitive parametric CAD modelling in virtual reality (OpenXR) for FreeCAD.

## Prerequisites

* Any HMD supported by OpenXR (HTC Vive, Valve Index, Oculus Rift, a Windows Mixed Reality headset, Steam Frame)

Note: the OpenXR runtime has to support [XR_KHR_opengl_enable](https://registry.khronos.org/OpenXR/specs/1.1/man/html/XR_KHR_opengl_enable.html) extension.

## Controls

The left controller carries the palette of tools and panels, the right controller is the tool hand. The grips move, turn and scale the world. The controls are described in [docs/ux-design.md](docs/ux-design.md).
